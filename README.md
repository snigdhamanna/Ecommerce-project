# 🛒 Django E-Commerce Website

A full-stack e-commerce web application built using **Python and Django**. The project provides essential online shopping functionality, including user authentication, email verification, product variations, cart management, order processing, and PayPal payment integration.

## ✨ Features

### 👤 User Authentication

* User registration and login
* User logout
* Email verification during registration
* Secure password handling
* User account management

### 🛍️ Product Management

* Product listing
* Product detail pages
* Product categories
* Product variations
* Product pricing
* Product stock management
* Product images

### 🛒 Shopping Cart

* Add products to cart
* Update product quantity
* Remove products from cart
* Support for product variations
* Automatic subtotal and total calculation

### 📦 Orders & Checkout

* Checkout functionality
* Customer information
* Order creation
* Order item management
* Order total calculation
* Order confirmation
* Order payment status

### 💳 Online Payment

* PayPal payment integration
* Online payment during checkout
* Payment verification
* Payment status tracking

### 📧 Email Verification

* Email verification for newly registered users
* Verification link sent to the user's email
* Helps ensure that users register with a valid email address

## 🗄️ Database

The application uses **MySQL** as its database.

MySQL is used to store and manage application data including:

* Users
* Products
* Categories
* Product variations
* Cart information
* Orders
* Order items
* Payment information

---



## 💳 Payment Integration

The application integrates **PayPal** to provide online payment functionality.

The payment flow allows users to:

1. Add products to their cart
2. Proceed to checkout
3. Review their order
4. Make payment through PayPal
5. Complete the order after successful payment

---

## 📧 Email Functionality

Email functionality is implemented for **user account verification**.

After registration, users receive a verification email containing a link to verify/activate their account.
